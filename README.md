# realAllenSong/homebrew-tap

Homebrew tap for [ThunderTalk](https://github.com/realAllenSong/ThunderTalk), free and open-source local voice input for macOS.

```sh
brew install --cask realallensong/tap/thundertalk
```

Apple Silicon, macOS 15 (Sequoia) or later. The app updates itself; `brew upgrade --cask thundertalk` works too.
